# AgroManager

Мобильное приложение для фермеров и небольших крестьянских хозяйств Кыргызстана: учёт полей и посадок,
календарь полевых работ, доходы и расходы, урожай и урожайность, прогноз погоды с предупреждениями о заморозках.

Приложение работает без интернета — все данные хранятся на телефоне. Интернет нужен только для прогноза погоды.

## Возможности

| Модуль | Что умеет |
|---|---|
| **Главная** | Приветствие, погода, количество полей и площадь, сколько культур растёт, прибыль и урожай за год, ближайшие и просроченные работы |
| **Поля** | Участки с площадью, типом почвы, местом и статусом (вспахано, засеяно, вегетация, урожай собран, под паром). В карточке поля — текущая культура, финансы по полю, затраты на 1 га, работы и история урожая |
| **Культуры** | Посадки с сортом и датами, прогресс до сбора, подсказка даты сбора по сроку созревания культуры, средняя урожайность по культурам |
| **Календарь** | Месячный календарь работ: полив, удобрение, посадка, обработка, сбор урожая. Работы отмечаются выполненными |
| **Финансы** | Доходы и расходы по категориям (семена, удобрения, топливо, оплата труда, продажа урожая, субсидии и др.), прибыль, рентабельность, структура расходов, сводка по годам. Периоды: месяц, год, всё время |
| **Урожай** | Записи сборов по годам, урожайность в центнерах с гектара |
| **Погода** | Текущая погода и прогноз на 7 дней для 11 городов Кыргызстана, предупреждения: заморозки, жара от +35°C, сильные осадки |
| **Профиль** | Имя фермера, название хозяйства, город для погоды, загрузка демо-данных, удаление всех данных |

Интерфейс на русском языке, Material 3, светлая и тёмная тема. Суммы — в сомах, урожайность — в ц/га.

## Технологии

- **Flutter / Dart** — Android и iOS
- **provider** — управление состоянием (`ChangeNotifier`)
- **shared_preferences** — локальное хранение данных в JSON
- **http** — запросы к погодному API [Open-Meteo](https://open-meteo.com/) (бесплатный, без ключа)
- **intl**, **flutter_localizations** — русская локализация дат и чисел
- **uuid** — идентификаторы записей

## Архитектура

```
UI (screens, widgets)  →  AppState (provider, ChangeNotifier)  →  shared_preferences (JSON)
                       →  WeatherState → WeatherService (http)  →  Open-Meteo API
```

```
lib/
├── main.dart                 запуск: загрузка данных, провайдеры
├── app.dart                  тема Material 3, русская локализация
├── models/
│   ├── enums.dart            почвы, статусы полей, культуры, типы работ, категории финансов
│   └── models.dart           Field, Planting, FarmTask, FinanceEntry, Harvest, Profile (+ toJson/fromJson)
├── state/
│   ├── app_state.dart        всё состояние хозяйства, бизнес-логика, сохранение
│   └── demo_data.dart        генератор демо-хозяйства с историей с 2023 года
├── services/
│   └── weather_service.dart  запрос прогноза, расчёт предупреждений
├── screens/                  главная, поля, культуры, календарь, финансы, урожай, погода, профиль, формы
├── widgets/                  общие карточки и элементы списка
└── utils/format.dart         форматирование денег, дат, веса, урожайности
```

**Как устроено хранение.** Каждое изменение в `AppState` вызывает `notifyListeners()` — экраны обновляются
автоматически — и сохраняет всё состояние в JSON через `shared_preferences`. При запуске данные загружаются обратно.

**Правила предметной области:**
- на поле одна текущая культура: новая посадка закрывает предыдущую и меняет статус поля на «Засеяно»;
- при записи урожая посадка завершается, а статус поля меняется на «Урожай собран»;
- в записи урожая сохраняется площадь на момент сбора, чтобы урожайность не менялась при редактировании поля;
- удаление поля удаляет его посадки, работы и урожай, а финансовые записи сохраняются (отвязываются от поля);
- средняя урожайность по культуре считается взвешенно по площади: общий урожай / общая площадь.

## Запуск

Требуется Flutter 3.38+ (проверено на 3.47) и Android-эмулятор или телефон.

```bash
flutter pub get
flutter run
```

В Android Studio: откройте папку проекта, выберите устройство и нажмите **Run**.

## Демо-данные

На главной (если полей ещё нет) кнопка **«Демо-данные»** или **Профиль → «Загрузить демо-данные»**.

Загружается крестьянское хозяйство «Ак-Жол» (Чуйская область) с историей **с весны 2023 года по сегодняшний день**:

- 5 полей, 15,8 га: собственные участки, огород, арендованное с 2024 года поле и люцерна на сено с 2025 года;
- севооборот: картофель, фасоль, кукуруза, ячмень, пшеница, подсолнечник, сахарная свёкла, томаты, капуста, лук, люцерна;
- около 200 финансовых записей: семена, топливо, удобрения, вода, оплата труда, аренда, ремонт и покупка техники,
  субсидии, продажи урожая;
- урожай по годам: засушливый 2023 год с пониженной урожайностью, удачный 2026-й;
- текущие посадки (озимая пшеница, озимый ячмень, люцерна) и работы на ближайшие дни, одна работа просрочена.

Даты считаются от текущего дня, поэтому данные всегда «свежие». Повторная загрузка заменяет все данные примером.

## Тесты

```bash

flutter analyze
```

Тесты проверяют расчёт урожайности, доходы и расходы, сохранение в JSON и загрузку, логику посадок и удаления поля,
историю демо-данных, предупреждение о заморозках и запуск приложения с переключением вкладок.
